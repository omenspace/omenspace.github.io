What it controls

Everything the daemon touches, it touches directly — WMI, ACPI, sysfs, and MSR — no vendor utility running underneath.

📈

Custom fan curves

Draw your own spline and the daemon holds it, smoothed by a moving average so a temperature spike doesn't set the fans flapping.

⚡

Thermal profiles

Switch between power-saver, balanced, and performance instantly, applied straight through ACPI and WMI.

🌈

RGB keyboard lighting

4-zone or per-key control over static colors, breathing, wave, and cycle effects, hardware-accelerated over sysfs.

🔧

Ryzen SMU & undervolting

Drop core voltage, set TCC offsets, and cap GPU TGP directly through MSR access, without leaving Linux.

🎮

GPU MUX switch

Flip between integrated and discrete graphics routing using the same WMI payload HP's own tooling relies on.

💻

CLI, tray & BIOS checks

Script changes from the terminal, watch things from the tray applet, or let the daemon check HP's own servers for firmware updates.

Inside the interface

Native GTK4 and Libadwaita, running in user space — the daemon does the privileged work over D-Bus.

How it's put together

Four Rust crates and a kernel module, split so nothing user-facing needs root.

omen-guiGTK4 + Libadwaita
omen-cliterminal control
omen-traypanel applet
D-Bus — org.hp.omen.*
omen-space-daemonsystemd service, root privileges
hp-omen-extraDKMS kernel module — WMI, sysfs, RGB

Install in one line

The web installer detects your package manager, resolves dependencies, and builds with release optimizations.

recommended
$ curl -sSL https://raw.githubusercontent.com/yunusemreyl/omen-space/main/install.sh | sudo bash
Other install methods (git clone, Arch, NixOS)
git clone
$ git clone https://github.com/yunusemreyl/omen-space.git $ cd omen-space && chmod +x setup.sh $ sudo ./setup.sh install
Arch Linux (AUR / PKGBUILD)
$ makepkg -si
NixOS (flakes)
$ nix profile install github:yunusemreyl/omen-space
