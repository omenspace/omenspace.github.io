What it controls

Direct hardware access through WMI, ACPI, sysfs, and MSR. No bloatware.

📈

Custom fan curves

Draw your own spline and the daemon holds it, smoothed by a moving average.

⚡

Thermal profiles

Switch between power-saver, balanced, and performance instantly.

🌈

RGB keyboard lighting

4-zone or per-key control over static colors and animated effects.

🔧

Ryzen undervolting

Drop core voltage and set TCC offsets directly through MSR access.

🎮

GPU MUX switch

Flip between integrated and discrete graphics routing effortlessly.

💻

CLI & Tray

Script changes from the terminal or watch hardware temps from the tray.

Inside the interface

Native GTK4 and Libadwaita for a seamless modern Linux experience.

Architecture

Split design so user-facing UI never needs root privileges.

Install in one line

The installer detects your distro and handles dependencies automatically.

Terminal
$ curl -sSL https://raw.githubusercontent.com/yunusemreyl/omen-space/main/install.sh | sudo bash
View manual install methods
Git Clone
$ git clone https://github.com/yunusemreyl/omen-space.git $ cd omen-space && chmod +x setup.sh $ sudo ./setup.sh install
Arch Linux (AUR)
$ makepkg -si
