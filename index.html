Donanımınıza
Hükmedin.

HP Omen ve Victus cihazlar için Linux üzerinde geliştirilmiş tam kapsamlı, modern ve inanılmaz hızlı donanım kontrol merkezi.

İndir Özellikleri İncele GitHub

Modern. Hızlı. Yerel.

Rust ve GTK4 kullanılarak sıfırdan inşa edildi. Arka planda sistem kaynaklarınızı tüketmeyen mimarisi sayesinde oyun oynarken veya yoğun iş yükü altında performans kaybı yaşamazsınız.

  • Natif GTK4 arayüzü ile muhteşem akıcılık
  • Rust ile yazılmış güvenli ve bellek dostu arka plan servisi
  • Wayland ve X11 ile tam uyumluluk
Tüm Özellikleri Gör

Sınırsız Özellikler

Cihazınızın potansiyelini son damlasına kadar kullanın. İhtiyacınız olan her şey tek bir merkezde toplandı.

Gelişmiş Güç Yönetimi

Güç profillerini değiştirin, TGP limitlerini ayarlayın ve pil ömrü ile performans arasındaki mükemmel dengeyi bulun.

RGB Stüdyosu

Bölgesel veya tuş bazlı aydınlatma kontrolü. Animasyonlu efektler yaratın veya statik renklerle sadeliği yakalayın.

Ryzen Undervolt

Isınma sorunlarına son. AMD işlemcinizin voltajını düşürün, TCC limitlerini belirleyin. Doğrudan donanım seviyesinde erişim.

MUX Switch

Oyunlarda maksimum performans için harici ekran kartına doğrudan bağlanın veya pil ömrü için hibrit modu seçin.

Sistem Tanılama

Donanımınızın durumunu anlık olarak izleyin. Fan hızları, sıcaklıklar, frekanslar ve kullanım oranları gözünüzün önünde.

Geniş Ayarlar

Uygulamayı kendi zevkinize göre özelleştirin. Başlangıç davranışları, tema ayarları ve dil seçenekleri ile tam kontrol.

Alternatif Çözümler

Linux ekosisteminde OMEN ve Victus cihazlar için geliştirilmiş diğer değerli açık kaynak projeler.

OmenCore

Termal profiller ve fan kontrolü için ilham aldığımız temel projelerden biri. Komut satırı (CLI) üzerinden güçlü sistem istatistikleri ve donanım yönetimi sunar.

Projeyi İncele

OpenOmen

Omen cihazlar için geliştirilen, klavye aydınlatması ve temel fan kontrollerine odaklanan başka bir açık kaynaklı alternatif grafik arayüz projesi. Sade ve işlevsel bir deneyim sunmayı amaçlar.

Projeyi İncele

Mimari ve Gelişim

OMENSpace, eski Python tabanlı OmenCtl projesinin Rust ile sıfırdan yazılmış, sıfır maliyetli soyutlamalar (zero-cost abstractions) sunan halidir.

Özellik / Metrik Eski OmenCtl (Python) OMENSpace (Rust)
Performans ve RAM ~40MB RAM (Python yükü) ~2.8MB binary, < 5MB RAM (Sıfır ek yük)
Mimari Senkron döngüler, alt süreç (subprocess) Tokio Async, Zero-fork /proc & Sysfs
GUI Altyapısı Python GTK Bindings (Hantal) Native GTK4 & Libadwaita (İnanılmaz hızlı)
Haberleşme pydbus zbus (Saf Rust, yüksek eşzamanlılık)
Donanım Kontrolü Standart ACPI Güç Profilleri Ryzen SMU, Undervolting & Fan Temizleme!

Backend (Daemon)

Arka planda root yetkileriyle çalışan systemd servisi. WMI, ACPI, Sysfs ve MSR üzerinden donanımla güvenli bir şekilde konuşur.

Frontend (GUI & CLI)

GTK4 ve Libadwaita ile inşa edilmiş modern arayüz (omen-gui) ve terminal aracı (omen-cli). Sudo gerektirmeden Daemon ile haberleşir.

Kernel Modülü

Özel DKMS sürücüsü (hp-omen-extra). Fanlar, termal sensörler ve RGB kontrolü için genişletilmiş donanım arayüzleri sağlar.

OMENSpace Kurulumu

Terminalinizi açın ve size uygun komutu yapıştırın.

1-Line Web Installer (Önerilen)
curl -sSL https://raw.githubusercontent.com/yunusemreyl/omen-space/main/install.sh | sudo bash

🟢 Stable (Kararlı)

curl -sSL https://raw.githubusercontent.com/yunusemreyl/omen-space/main/install.sh | sudo bash -s -- --stable

🟡 Canary (Geliştirici)

curl -sSL https://raw.githubusercontent.com/yunusemreyl/omen-space/main/install.sh | sudo bash -s -- --canary
📦 Alternatif Kurulum Seçenekleri

Git Clone (Ubuntu, Fedora, vb.)

git clone https://github.com/yunusemreyl/omen-space.git
cd omen-space
chmod +x setup.sh
sudo ./setup.sh install

Arch Linux (AUR / PKGBUILD)

git clone https://github.com/yunusemreyl/omen-space.git
cd omen-space
makepkg -si

NixOS (Flakes)

nix profile install github:yunusemreyl/omen-space
